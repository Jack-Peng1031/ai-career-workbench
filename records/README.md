# 记录区（你自己写东西的地方）

工作台只在下面这些固定路径里找"完成证据"。文件不存在时，第一天的内容会自动以模板形式出现在这里。

```
records/
├── code/
│   ├── 刷题日志.md          每天一行：题目、难度、卡点、复杂度
│   ├── 模板/                算法模板（蓝桥杯/竞赛用）
│   └── ai-basics/           AI编程基础-1、实训-1 的每周代码
├── english/
│   ├── 生词本.md            当天连续错的词（≥5 条）
│   └── 模考记录.md          每次四级模考：分数 + 最弱题型
├── research/
│   ├── 前沿阅读.md          每篇三句话：什么问题 / 怎么做 / 和哪门课有关
│   └── 导师与方向.md        感兴趣的 3 位老师及方向
├── info/
│   └── 保研细则存档.md      绩点算法、加分项、名额比例（最关键的侦察成果）
└── reviews/
    └── 2026-W40.md          每周复盘：做对了什么 / 失控点 / 下周只改一件事
```

## 打卡与记录的配合方式

- `python app.py done <序号>` 表示"确认完成"，写进 `state/completions.json`。
- 记录文件是**给未来的你看的证据**：保研面试时，能拿出连续 300 天的刷题日志和 12 篇前沿阅读摘要，比任何自述都有说服力。
- 数量类任务（刷题、模考）请用 `--amount` 填真实数字：

```powershell
python app.py done leetcode --amount 3
python app.py done english-mock --amount 428
```

这样累计进度条反映的是真实产出，而不是"点过的次数"。
