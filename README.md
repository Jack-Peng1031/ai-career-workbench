# AI 职业生涯规划 · 学习实践工作台

四川大学 人工智能专业 2026 级 · 保研优先 / 考研兜底双轨

**这个工作台解决四件事：**

1. **每天早上给你一份 todo 清单** —— 由课程表 + 保研路线自动编译，不是手写的愿望清单。
2. **你确认完成，它记录并统计** —— 刷题量、单词天数、模考次数、区间完成率全部自动累计。
3. **随时改计划** —— 计划写在一个 `plan.json` 里，改完重算，未来所有日子的清单立刻更新。
4. **加新材料就能细化** —— 把教学大纲、校历、保研细则丢进 `materials/`，程序自动登记并提示要改哪一块。

## 一、30 秒上手

```powershell
cd D:\WorkSpace\ai-career-workbench

# 今天的 todo
python app.py today

# 完成第 1、2、3 条
python app.py done 1 2 3

# 刷题完成并填写真实题量（进度条按真实数量走）
python app.py done leetcode --amount 3

# 打开可视化工作台（勾选框可点击，自动存盘）
python app.py serve --port 8765     # 然后浏览器打开 http://127.0.0.1:8765/
```

不想敲命令：**双击 `start.bat`**（或右键「使用 PowerShell 运行」`start.ps1`）会出现菜单：

```
1  今天的 todo 清单          5  加了新材料后重算计划
2  打开可视化工作台          6  导出 Markdown 打卡清单
3  未来 7 天一览             7  自定义任务列表
4  学习实践报告              0  退出
```

也可以直接带命令调用：`start.bat today`、`start.bat report --quarter`。

> **关于服务进程**：工作台服务跑在**前台**，关掉那个窗口它就停了——这是有意的，
> 不会在你机器上留下看不见的后台进程。再点一次菜单第 2 项也不会起第二个实例：
> 端口被占用时它只打开浏览器。若发现端口上有残留进程，用
> `powershell -ExecutionPolicy Bypass -File start_server.ps1 -Port 8765 -Stop` 清掉。
>
> 只勾选打卡必须走服务；**不点勾、只看清单**的话，直接双击 `dashboard.html` 就能离线看
> （页面里的「添加/删除自定义任务」会提示需要从服务打开）。

> 说明：`done` 后面的数字就是 `today` 打印出来的序号；课程行不占编号。

## 三、命令全表

| 命令 | 作用 |
|---|---|
| `python app.py today [--date 2026-10-08]` | 生成某天的 todo 清单（默认今天） |
| `python app.py week [--days 7]` | 未来若干天一览 |

| `python app.py addtask "标题" --from 2026-10-01 --to 2026-10-31 --days 6,7 --minutes 20` | **新增自定义任务**（某一天或一个时间段，会进每日清单） |
| `python app.py tasks` | 列出自定义任务 |
| `python app.py deltask <id>` | 删除自定义任务（连带清掉它的打卡记录） |
| `python app.py report [--month\|--quarter\|--year]` | 学习实践报告；`--range 2026-09-30..2026-12-31` 自定义区间 |
| `python app.py replan` | **加了新材料或改了计划后重算未来 120 天** |
| `python app.py export --days 30` | 导出 Markdown 打卡清单（可打印） |
| `python app.py materials [--guide]` | 看材料库与待补充清单与格式要求 |
| `python app.py serve --port 8765` | 本地可视化工作台（可勾选、可加/删自定义任务，自动存盘） |

自检：`python tools/selftest.py`（111 项），`python tools/check_dashboard.py`（页面与 JS 检查）。

### 网页端「自定义任务」

打开工作台后，右栏有一张 **自定义任务** 卡片，不用命令行也能加：

- **只有一天**：只填开始日期（结束日期留空）；
- **一个时间段**：填开始 + 结束日期；**勾选星期**则只在这些天出现（例如只勾「周六」「周日」＝整个 10 月每个周末都出现）；
- 可填分钟数、步骤（每行一条）、完成标准。

添加后：任务会出现在对应日期的**今日清单**里（可勾选存档），并进入**接下来要盯的日期**时间线（标为"自定义"）。
卡片下方列出所有自定义任务，点「删除」即可移除（会一并清掉它产生的打卡记录）。

命令行等价操作：

```powershell
# 每个周末的晨跑，10 月整月，30 分钟
python app.py addtask "周末晨跑" --from 2026-10-01 --to 2026-10-31 --days 6,7 --minutes 30
# 只加一天
python app.py addtask "交实验报告" --from 2026-10-14 --minutes 45 --steps "写完报告|导出PDF提交" --proof "提交成功截图"
python app.py tasks            # 看列表和 id
python app.py deltask c9316fe62
```

> 提示：**每天的校园跑、慕课作业、学习通作业已经写进计划**（见下表），不需要再手动加。
> 自定义任务适合"临时多出来的事"：补交作业、班会、体检、报名的截止日等。

| 固定周任务 | 时间 | 说明 |
|---|---|---|
| 校园跑 20 分钟 | 每周六、周日 | 时长固定不被放大；雨天改室内替代 |
| 英语慕课网作业 40 分钟 | 每周六、周日 | 周六做、周日清尾（含讨论区/互评） |
| 英语学习通作业 40 分钟 | 每周一 | 周一先清作业，本周不再惦记 |

> **这几项标了 `always`，不会被假期/期末阶段"收窄"掉。**
> `phase_overrides` 里的 `keep_task_ids`（国庆、期末复习期）会把当天的任务收窄成"只保留几项"，
> 但校园跑是体育课要求、英语作业是平台布置的，**放假也不会消失**，所以它们带
> `always: true` 豁免收窄。普通任务（如 AI 编程实操）仍会照常被收窄。
> 反过来，如果你希望某个阶段暂停某项任务，把它的 `scale` 设为 `0` 即可
> （例如 `"scale": {"campus-run": 0.0}`）。

### 「接下来要盯的日期」按日期折叠

右栏时间线**折的是每一天，不是每条说明**——所以一屏能扫完十几个日期：

- **收起时**只看到一行摘要：`日期 · 星期 · 还有几天 · N 项`；
- **点这一行**才展开那天要做的事（按天分组，同一天有多件事也没问题）；
- **前 5 项加载时就展开**（最近的几件事先看到），其余收起；
- **任务标题永远完整显示**：占满整行、需要就换行，不会出现 `后半部分被省略号截掉`；
- 超过 12 天的部分默认不出，点顶部「展开/收起全部日期」一次性放出；
- 标题右侧显示总天数，例如「点日期展开 · 共 24 天」。

### 「本周全景」：点某一天的格子，下面只看那天

左栏第二张卡片是**点选式**的，不再一次性铺开整周清单：

- **上面 7 个格子**：每格显示 `星期 / 日期 / 还有几天 / N 课 · M 任务`，底部小柱条＝当天
  自主任务的完成比例（越短＝越没推进）；
- **点任意一个格子** → 下面立刻换成**那一天的事项**，格子本身变成深色高亮
  （高亮由 JS 显式切换：先清掉所有格子的高亮、再给点中的那个加上，所以来回点都不会失灵）；
- **下面只列任务本身**，不再重复"日期 / 几门课 / 多少分钟"这些格子里已经有的信息
  （只在顶部留一行轻量的日期＋星期＋今天/明天做定位）；
- 任务带**彩色轨道标签**（绩点/代码/英语/科研/课程/阶段/自定义）与状态胶囊（已完成/今天/临近）。

> 7 天的清单都渲染进 `dashboard.html`（纯前端切换、不联网），所以静态托管同样可用，
> 也正因为只显示一天，页面从 137 KB 降到 79 KB。

### 左栏 / 右栏的分工与宽度

| 位置 | 内容 |
|---|---|
| 左栏（自适应宽度） | 今日清单 → 本周全景 → 阶段里程碑 → **自定义任务**（表单较宽，放最下面） |
| 右栏（固定 400px） | 区间完成率 → 累计进度 → 接下来要盯的日期 → 本学期课表 → 材料库与待补充 |

右栏从 340px 加宽到 **400px**，并且两栏用 `align-items:start` 各自按内容收尾——否则左栏会被
右栏的长列表拉高、卡片里留出一大片空白。窄栏里两处容易"竖排"的地方也做了处理：
`已入库` 状态不换行、`周六` 这类星期不可拆行。

「接下来要盯的日期」**前 5 项加载时自动展开**，其余收起，点顶部「展开/收起全部日期」一次性放出。

### 主题与配色（层次 + 提示）

页面用一套 CSS 变量管配色，改 `render_dashboard.py` 顶部的 `CSS` 即可整体换色：

| 变量 | 作用 |
|---|---|
| `--bg / --sunken / --panel / --panel-2 / --raised` | 五层表面：页面底 → 下沉 → 卡片 → 卡片内层 → 浮起 |
| `--primary / --primary-deep / --primary-soft` | 主色，用于标题竖条、当前日期、链接、主按钮 |
| `--ok / --warn / --danger / --info` | 语义色：完成=绿、提醒=琥珀、冲突/逾期=红、常规=蓝 |
| `--gpa / --code / --english / --research / --class / --phase / --extra / --custom` | 各条线的专属色，任务左侧色条与标签同色 |

**层次感**来自：顶栏渐变 + 光斑、卡片顶部渐隐色带、卡片标题「有色底 + 下边线 + 左侧主色竖条」、
五行分层背景、进度条/柱条统一圆角。**提示作用**来自：语义色胶囊（今天/明天/N 天后/已完成）、
完成度低于 50% 的柱条明显偏空、时间线上今天用主色高亮。
深色模式（`prefers-color-scheme:dark`）另有一套变量，不要只改亮色。

## 四、计划怎么改（这是"以后加材料"的关键）

计划的唯一真源是 **`plan.json`**。它分六块，改哪一块取决于你拿到什么材料：

| 材料 | 改 `plan.json` 的哪块 | 例子 |
|---|---|---|
| 新课程表 / 换课 | `course_meetings` | 换体育项目、新增选修课 |
| 讲座 / 开放日 / 报告会（单次、有确定日期） | `fixed_events` | 教授开放日：某天某节次，只出现一次 |
| 教学大纲、考核方式 | `task_templates` | 某课平时分占 40% → 给它的复盘加步骤 |
| 校历、考试安排 | `key_dates`、`calendar.semester` | 期末考试周、四级/竞赛日期 |
| 保研细则、加分政策 | `milestones`、`task_templates` 权重 | 加分项变了就改 30/90/365 天验收标准 |
| 期中/期末/假期 | `phase_overrides` | 已经预设了国庆、期中、期末复习期、寒假 |
| 新增日常任务 | `task_templates` | 加"每天 30 分钟英语听力" |

> **临时任务不走 `plan.json`**：一次性的、只影响某几天的事（补交作业、班会、体检）
> 用网页端「自定义任务」卡片或 `app.py addtask`，存在 `state/cache/custom_tasks.json`，
> 不污染计划真源。要**长期**每天都做的新习惯，才写进 `task_templates`。

**改完一定要执行：**

```powershell
python app.py replan
```

它会重建未来 120 天的清单快照、刷新 `dashboard.html`，并告诉你哪些新文件已登记。

### 加新材料的完整流程

1. 把文件（`.md` / `.txt` / `.csv` / `.docx` / `.pdf` / `.xlsx` 都行）放进 `materials/`；
2. 运行 `python app.py replan` —— 新文件会被登记进 `state/materials.json`；
3. 如果它会改变计划，编辑 `plan.json` 对应区块，再跑一次 `replan`；
4. 或者直接把材料发给我（AI），我读完帮你把 `plan.json` 改好、验证、刷新页面。

### `materials/` 的格式要求

没有"必须是什么格式"的硬性门槛，但**程序能直接读懂的程度差别很大**：

| 要求 | 说明 |
|---|---|
| 编码 | 文本文件必须是 **UTF-8**；GBK/GB18030 会乱码，先转码再放进来 |
| 格式 | `.md` / `.txt` / `.csv` / `.json` 可直接读；`.docx` / `.pdf` / `.xlsx` 需要先转文本（或直接发我，我读完替你转） |
| 命名 | 正常命名即可；**以 `_` 开头的文件会被忽略**（如 `_extract_pdf_text.txt`），可用来放中间产物 |
| 体积 | 单个文件建议 < 5 MB |

想让我一次就读对，写成这样最省事：

- **表格**：用 `|` 分隔的 Markdown 表格，第一行写表头。按列名取值比按位置猜稳得多——`讲座.txt` 就是这种（制表符分隔也可）。
- **日期**：统一写 `2026-10-09`；**同时写上教学周**（如"第6周"）更好，两份数据能互相校验。这次就是靠它印证了"9/30 = 第5教学周"。
- **时间**：写"第7-9节"或"14:00-16:25"，前者能直接和课表比对出冲突。
- **开头**：用一句 `# 一句话说明这份材料是什么、要我改什么`。

登记后可用 `python app.py materials` 查看当前材料与格式要求原文。

工作台里预设了**待补充材料清单**（在仪表盘右栏），补上这些就能把计划从"骨架"细化到"日程"：

- 各科教学大纲 / 考核方式（决定平时分策略）
- 校历与期末考试安排
- 保研细则（绩点算法、加分项、名额比例）
- 转专业 / 辅修政策
- 目标竞赛的历年真题与报名通知

**关于端口：** 服务默认用 8765。如果该端口已被占用，它会自动顺延到 8766 并在控制台
打印一行提示——**以打印出来的那个地址为准**。服务是"独占端口"的，同一端口不会出现两个
进程同时监听（否则页面会随机显示旧内容）。

## 五之二、GitHub + PythonAnywhere 部署与同步

两条独立的通道，**别混**：

| 通道 | 管什么 | 命令 |
|---|---|---|
| Git | 版本历史（代码、计划、材料、生成物） | `gitpush.bat`（双击）或 `git push` |
| PythonAnywhere | 线上那份实际文件（`https://JackPeng.pythonanywhere.com/`） | `syncPA.bat`（双击）或 `python tools/pa_sync.py push` |

### 首次配置（只做一次）

```powershell
python tools/pa_sync.py setup     # 生成密钥并打印公钥
```

把打印出来的那一行公钥粘到 PythonAnywhere：
**登录 → 右上角 `Account` → 页面里的 `SSH keys` 小节 → 新建并保存**。
粘好后验证：

```powershell
python tools/pa_sync.py check     # 应显示「SSH 认证通过」并列出远端文件
```

> 不想开 SSH 也可以：在 `Account → API token` 拿一个 token，写进项目根目录的
> `.pa_sync.json`（该文件已在 `.gitignore` 里，不会进仓库）：
> ```json
> {"user": "JackPeng", "remote_dir": "ai-career-workbench",
>  "token": "你的token", "domain": "JackPeng.pythonanywhere.com"}
> ```
> 之后用 `python tools/pa_sync.py push --api` 走 Files API（无需 SSH），
> `python tools/pa_sync.py reload` 还能远程触发 Reload。

### 日常用法（`syncPA.bat` 双击即可）

| 菜单 | 等价命令 | 作用 |
|---|---|---|
| 1 | `pa_sync.py check` | 检查认证、远端目录、两边文件数 |
| 2 | `pa_sync.py diff` | 只看差异，**不修改任何文件** |
| 3 | `pa_sync.py push` | 本地 → PythonAnywhere |
| 4 | `pa_sync.py push --reload` | 上传 + 重新加载 Web App |
| 5 | `pa_sync.py pull` | PythonAnywhere → 本地（会覆盖本地同名文件） |
| 6 | `pa_sync.py setup` | 显示 SSH 公钥 |
| 7 | `pa_sync.py reload` | 只重新加载 Web App |

不同步的目录：`state/`、`logs/`、`exports/`、`records/`、`__pycache__`、`.git/`
——即"本机运行数据"不上传；打卡记录始终以本机 `state/completions.json` 为准。
以 `_` 开头的文件（本机调试用的临时脚本）也不会被上传。

不带 SSH 也能用：`python tools/pa_sync.py check --api` 验证 token，
`push --api` 走 Files API 逐文件上传。**线上是 WSGI 应用**（`wsgi_standalone.py` + Python 3.10），
所以 `push` 完要用 `reload` 让改动生效。

推完想知道线上到底对不对，跑一条命令即可（会拉真实页面与接口来验）：

```powershell
python tools/verify_deploy.py      # 线上页面/接口自检：14 个逐日清单块、主题变量、/api/day
```

> 该脚本校验的是 `https://jackpeng.pythonanywhere.com/`：首页是否为新版、
> 「本周全景」是否铺开了 14 天逐日清单、新主题变量是否生效、
> `/api/day` 与 `/api/day?date=...` 是否正常、有没有乱码。

> **静态挂载 vs WSGI/Flask**：如果 PythonAnywhere 上只是把 `dashboard.html` 当静态文件映射到
> URL，那么 `push` 之后**刷新浏览器就能看到新版**，不用 Reload；
> 如果挂的是 Flask/WSGI 应用，`push` 后需要点一次 Web 标签页的 **Reload**（或按菜单 7）。
> 本页面的「本周全景逐日清单」「自定义任务表单」是**内联渲染**的，静态挂载也能正常显示；
> 但左栏的**勾选存档**与**增删自定义任务**依赖本地服务接口（`python app.py serve`），
> 在纯静态网站上点击会提示"未保存"——这是预期行为，不是 bug。
