# 四川大学 人工智能专业 培养方案（2026—2030）

> 来源：`人工智能培养方案.txt`（教务处导出）。本文件是工作台的课程地图，用于把"哪门课在第几层、什么时候上、对保研/考研有什么用"讲清楚。

## 一、课程体系：三层结构

| 层级 | 核心课程 / 环节 | 战略含义 |
|---|---|---|
| 第一层 数理编程基础 | 微积分（Ⅰ）-1/-2、线性代数（理工）、概率统计（理工）、大学物理（理工）Ⅲ-1、AI编程基础-1/-2（双语）、离散数学、科学计算 | 大一到大二的看家本领。绩点权重最高，也是所有后续课的地基 |
| 第二层 专业核心 | 人工智能引论、数据结构与算法分析、机器学习引论（双语）、深度学习引论（双语）、计算机视觉与数字图像处理、自然语言处理、大模型概论及应用、数据库系统原理（双语）、强化学习基础、类脑计算基础、最优化理论、矩阵分析与应用 | 大三硬核主战场；保研面试问得最凶的区间 |
| 第三层 实践与科研 | AI编程基础实训-1/-2、AI编程综合实践、数据结构与算法分析课程设计、离散数学课程设计、各课程设计、科研创新训练-1/-2、专业实训、Summer Workshop、人工智能前沿进展、毕业设计 | 把知识变成履历的地方 |
| 通识与素质 | 选择性思政必修（N选1）、通识先导课（5选1）、通用英语Ⅰ/Ⅱ、专门用途英语、心理健康、劳动教育、美育、创新创业教育、体育-1~6、国家安全教育、军事理论/技能、新生研讨课、大学思想文化素养、新时代实践教育 | 决定综合素质分与德育评定，不可裸掉 |

## 二、公共基础课（必修）

体育-1 ~ 体育-6、国家安全教育、军事技能、新生研讨课、军事理论、
习近平新时代中国特色社会主义思想概论、新时代实践教育、大学生思想文化素养、
马克思主义基本原理、中国共产党历史与理论。

**英语系列**：通用英语-1 / 通用英语Ⅱ-1 / 通用英语Ⅰ-1；通用英语-2 / 通用英语Ⅱ-2 / 通用英语Ⅰ-2；
专门用途英语（医学英语 / 学术英语交流 / 学术英语写作）；跨文化交际（中国文化英语阅读 / 跨文化阅读 / 跨文化实用交际）。

**思政选择性必修（N选1）**：科技哲学史、四川大学校史文化、马克思主义宗教观、
中华民族共同体概论、改革开放史、新中国史、社会主义发展史、宪法法律、中国诗歌艺术、
巴蜀文化 等 27 门中任选。

**通识先导课（5选1）**：科学进步与技术革命 / 中华文化（哲学篇 / 艺术篇 / 文学篇 / 历史篇）。

## 三、学科基础课 · 大类平台课（必修）

微积分（Ⅰ）-1、AI编程基础-1、大学物理（理工）Ⅲ-1、微积分（Ⅰ）-2、线性代数（理工）、
人工智能引论、概率统计（理工）、AI编程基础-2（双语）、数据结构与算法分析、离散数学、
人工智能伦理与持续发展、最优化理论、矩阵分析与应用、科学计算。

## 四、专业核心课（必修）

计算机专业基础综合、计算机视觉与数字图像处理、自然语言处理、深度学习引论（双语）、
机器学习引论（双语）、大模型概论及应用、数据库系统原理（双语）、强化学习基础、类脑计算基础。

## 五、专业选修课（限选 / 选修）

计算思维、软件工程、模式识别、数据挖掘引论（双语）、算法设计、智能决策、进化计算、
神经建模与表征学习基础。

## 六、实践教育环节

- **必修实训**：AI编程基础实训-1/-2、AI编程综合实践、数据结构与算法分析课程设计、
  离散数学课程设计、计算机专业基础综合实践、科研创新训练-1、
  自然语言处理课程设计、计算机视觉课程设计、数据库系统原理课程设计、专业实训、
  人工智能前沿进展、毕业设计。
- **限选/选修**：理解与表达：学术前沿论文选读、互联网+多学科交叉创业设计与实践、
  科研创新训练-2、Summer Workshop。

## 七、这张表对行动的含义

1. **大一、大二只做一件事**：把第一、二层的"数学 + 编程"啃扎实，绩点自然高。
2. **大三被安排进 CV / NLP / ML / DL / 大模型集中输出的学期**，那是出科研作品和参加夏令营的弹药期。
3. **"科研创新训练"与"人工智能前沿进展"是学校主动留给你靠近科研的窗口**，务必当宝贝用。
4. 通识与思政课靠出勤 + 作业拿分，缺勤是纯亏；这类课不需要提前复习，但绝不能裸掉。

## 八、本工作台如何使用这份材料

- 课表已抽取进 `plan.json` 的 `course_meetings`。
- 若选课变动（例如换了思政课或体育项目），改 `plan.json` 对应条目后运行
  `python app.py replan` 即可重算每天的清单。
- 拿到新的**教学大纲 / 考核方式**后放进 `materials/`，运行 `python app.py replan`，
  再把"平时分构成"写进 `task_templates` 里对应课程的复盘步骤。
