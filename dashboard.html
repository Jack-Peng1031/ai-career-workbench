阶段里程碑

一个月 / 90 天 / 一年三道关，逐条打勾；不达标就当场调计划。

第 1 个月：把习惯与工具链立起来 截止 2026-10-30（30 天后）
  1. 微积分每天有演算痕迹，累计 ≥20 天
  2. LeetCode 累计 ≥30 题，刷题日志每天有记录
  3. 词汇累计 ≥22 天，四级核心词过完第一遍
  4. GitHub 仓库建好并有 ≥12 次提交
  5. AI编程基础-1 课后代码全部自己重敲过一遍
  6. 查清保研细则并存档（绩点算法、加分项、名额）
90 天：期末不塌方 + 四级过关 + 100 题 截止 2026-12-29（90 天后）
  1. 期末：微积分、AI编程基础、AI编程基础实训全部 ≥85 分（目标专业前30%）
  2. CET-4 首考参加，目标 550+
  3. LeetCode 累计 ≥100 题
  4. 完成蓝桥杯省赛报名
  5. 所有通识/思政课无缺勤、无挂科风险
  6. python 数据栈入门完成 Numpy+Pandas 基础
一年：大一学年收官，进入大二竞赛与科研 截止 2027-07-01（274 天后）
  1. 大一学年绩点进入专业前 30%
  2. 第16届/第17届蓝桥杯省赛拿到省三及以上
  3. LeetCode 累计 ≥300 题，会写常见模板
  4. CET-6 启动（或四级 550+ 已达成）
  5. 进入 1 个课题组旁听组会，或完成 1 次大创立项调研
  6. 确定主攻方向种子：CV / NLP / 大模型 / 数据挖掘 四选一
  7. 读完 1 本 Python 数据分析入门书并有配套代码仓库
